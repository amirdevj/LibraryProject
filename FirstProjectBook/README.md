# Library Management System

یک پروژه کنسولی با C# که برای تمرین و پیاده‌سازی مفاهیم Object-Oriented Programming (OOP) توسعه داده شده.

## داستان این پروژه

هدفم از ساخت این پروژه، این بود که مفاهیم OOP رو به‌جای حفظ کردن، در قالب یک برنامه واقعی‌تر تمرین کنم.

در این برنامه می‌شه کتاب‌ها و اعضای کتابخانه رو مدیریت کرد، کتاب به امانت داد، اون رو پس گرفت و بین آیتم‌های کتابخانه جست‌وجو انجام داد.

## امکاناتی که پیاده‌سازی کردم

- اضافه کردن کتاب و سایر Library Items
- ثبت اعضای جدید کتابخانه
- امانت گرفتن و بازگرداندن کتاب
- جست‌وجوی کتاب بر اساس ID یا Title
- نمایش فهرست آیتم‌های کتابخانه
- نمایش کتاب‌های امانت گرفته‌شده توسط اعضا
- مدیریت خطاها با Custom Exceptions

## مفاهیمی که در این پروژه تمرین شده‌اند

در طول توسعه این پروژه، از مفاهیم مختلف برنامه‌نویسی شیءگرا استفاده کردم:

- **Encapsulation:** کنترل دسترسی به داده‌ها و محافظت از وضعیت Objectها
- **Inheritance:** استفاده از یک Base Class برای انواع مختلف آیتم‌های کتابخانه
- **Abstraction:** استفاده از Abstract Class و Interface
- **Polymorphism:** کار با انواع مختلف Library Items از طریق یک Base Class مشترک
- **Interfaces:** تعریف رفتار امانت‌دهی با استفاده از `IBorrowable`
- **Exception Handling:** مدیریت خطاها با `try-catch` و Custom Exceptions

## نگاهی به فایل‌های پروژه

برای اینکه مسئولیت هر بخش مشخص باشه، کلاس‌های مختلف پروژه رو از هم جدا کردم:

| فایل | مسئولیت |
|---|---|
| `Program.cs` | نقطه شروع برنامه و مدیریت منوی کنسول |
| `Library.cs` | منطق اصلی مدیریت کتابخانه |
| `LibraryItem.cs` | کلاس پایه انتزاعی برای آیتم‌های کتابخانه |
| `Book.cs` | پیاده‌سازی کتاب |
| `EBook.cs` | پیاده‌سازی کتاب الکترونیکی |
| `Magazine.cs` | پیاده‌سازی مجله |
| `Member.cs` | مدیریت اعضای کتابخانه |
| `IBorrowable.cs` | تعریف قرارداد مربوط به امانت‌دهی |
| `Custom Exceptions` | مدیریت خطاهای اختصاصی برنامه |

## راه‌اندازی پروژه

برای اجرای پروژه به .NET SDK نیاز داری.

ابتدا Repository رو Clone کن:

```bash
git clone YOUR_REPOSITORY_URL
```

وارد پوشه پروژه شو:

```bash
cd FirstProjectBook
```

سپس برنامه رو اجرا کن:

```bash
dotnet run
```

همچنین می‌تونی پروژه رو مستقیماً با Visual Studio باز و اجرا کنی.
